# Tutorial Progresivo: ASPEN HYSYS + Python

Tutorial pedagógico con 8 prácticas progresivas para aprender automatización de ASPEN HYSYS con Python.

## 🎯 Objetivo

Enseñar a estudiantes de posgrado cómo integrar ASPEN HYSYS con Python mediante COM API, con aplicación en producción de biodiesel.

## 📋 Estructura

| Práctica | Tema | Duración | Dificultad |
|----------|------|----------|------------|
| **1** | Conexión básica con HYSYS | 30 min | ⭐ |
| **2** | Componentes y paquetes termodinámicos | 45 min | ⭐ |
| **3** | Corrientes de materia y energía | 1 hora | ⭐⭐ |
| **4** | Operación unitaria: Mixer | 1 hora | ⭐⭐ |
| **5** | Reactor CSTR (conversión fija) | 1.5 horas | ⭐⭐⭐ |
| **6** | Reactor con cinética de Arrhenius | 2 horas | ⭐⭐⭐⭐ |
| **7** | Reactores Batch vs Continuos | 2 horas | ⭐⭐⭐⭐ |
| **8** | Planta completa de biodiesel | 3 horas | ⭐⭐⭐⭐⭐ |

**Total**: ~10.5 horas

## 🚀 Inicio Rápido

```bash
cd practica1
python script.py
```

## 📖 Requisitos

- Python 3.7+
- ASPEN HYSYS v10+
- `pip install pywin32`

## 🎓 Uso

1. Lee README.md de cada práctica
2. Ejecuta script.py
3. Completa ejercicios guiados
4. Intenta retos adicionales
