CREAR REPOSITORIO EN GITHUB (OPCIONAL)

Si quieres publicar en GitHub:

   cd C:\aspenTuto\tutorialAspen

   git remote add origin https://github.com/TU_USUARIO/tutorialAspen.git

   git push -u origin main

   (Necesitaras tu usuario y Personal Access Token)
