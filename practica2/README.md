# Practica 2: Componentes y Paquetes Termodinamicos

Dificultad: * (Principiante)
Duracion: 45 min
Objetivo: Configurar componentes y paquetes termodinamicos en HYSYS

## Conceptos Clave

- FluidPackage - Contenedor de componentes
- Components.Add() - Agregar componentes
- PropertyPackage - Seleccionar modelo (NRTL, UNIFAC, etc.)
- Propiedades criticas: Tc, Pc, MW

## Objetivos

1. Agregar componentes desde libreria HYSYS
2. Seleccionar paquete termodinamico apropiado
3. Extraer propiedades criticas
4. Comparar NRTL vs UNIFAC
